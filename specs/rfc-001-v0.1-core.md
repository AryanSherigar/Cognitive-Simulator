# RFC-001: v0.1 Core and Validation Harness

## Status

Accepted implementation specification for the deterministic v0.1 simulator.

## Scope

Build a CPU-runnable, deterministic five-step simulation loop with strict Pydantic wire contracts, a deterministic body/subcortical layer, reconstructive memory with cooldown gating, a cortical backend protocol, a seeded mock backend, a llama.cpp adapter boundary, and Gate 1/Gate 2 validation runners. The mock path must run with `python -m evals.gate2_lesions.run --backend mock --seed 42`.

## Invariants

1. Body and environment logic are deterministic and contain no ML/LLM imports.
2. Typed contracts are frozen Pydantic v2 models with `extra="forbid"`.
3. Each tick executes: pre-appraisal decay, appraisal/post-appraisal impulse, memory priming, cortical formulation, objective resolution/consolidation.
4. Visceral appraisal occurs before memory priming.
5. Objective ground-truth events remain separate from subjective consolidation.
6. Stable persona/dialogue context is an immutable prompt prefix; current somatic cues and retrieved memories are an ephemeral tail.
7. Retrieval excludes traces when `current_tick - last_retrieved_tick < cooldown_ticks`, unless the cooldown lesion is enabled.
8. Physiological rates, thresholds, token caps, and cooldown are configured through `SimConfig`.

## Core contracts

The implementation provides frozen models for `Exteroception`, `Interoception`, `EnvState`, `AppraisalVec`, `ModulationSignal`, `CorticalTurnOutput`, `ConsolidationOutput`, and `MemoryTrace`. Numeric fields are bounded at schema boundaries and malformed backend output is rejected.

## Physiology

The body engine computes exponential adrenaline, HPA precursor, and cortisol decay before appraisal. Appraisal adds bounded SAM/HPA impulses and sets overload/shutdown flags at configured thresholds. Sensory values are discretized into deterministic tags.

## Validation

Gate 1 runs a six-turn industrial cooling audit across seeded personas and reports compliance, token compression, and consolidation drift. Gate 2 runs the same scenario under all five lesions and checks the expected directional shifts. Both are available on CPU through the mock backend.
